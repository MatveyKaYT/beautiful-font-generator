# Beautiful Font Generator
https://fontgen.notmtvk.pro/

EN:
This tool lets you quickly convert text into a wide or small font for use in your Minecraft server's MOTD. Simply type or paste your text, choose the conversion style you want, and you'll instantly get a result that's ready to copy and use.

These fonts have been used on many popular Minecraft servers for years to style their MOTDs. They help make your server description stand out and catch players' attention in the server list. If you've spent time playing on different servers, you've probably seen this style more than once.
